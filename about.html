Earlier projects

HOSVD image compression · 2022

For HSE Faculty of Computer Science summer practice, I implemented higher-order singular value decomposition and applied it to low-resolution PNG image compression. A compression-rate parameter controls the portion of singular values retained.

I wrote the entire project without AI assistance.

The repository includes the implementation and a PDF report describing the method and results.

Method reference

Lieven De Lathauwer, Bart De Moor, and Joos Vandewalle. “A Multilinear Singular Value Decomposition.” SIAM Journal on Matrix Analysis and Applications, vol. 21, pp. 1253–1278, 2000.
